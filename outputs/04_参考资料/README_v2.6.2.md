# 最终自适应上位机 v2.6.2

双击 `启动上位机.bat`，或直接运行 `NuclearMcaMonitor_FinalAdaptive_v2.6.2.exe`。旧版 EXE 统一保存在 `his` 文件夹，工作目录只保留当前启动版本；自检与无头渲染产生的预览截图、结果与诊断文件统一归档在 `test_artifacts` 文件夹（再次运行 `--self-test` 或 `--render-*` 时会重新生成到工作目录，可自行移入归档）。

v2.6.2 调整指标颜色规则：脉冲通过率 ≥99% 且 ≤100.1% 时绿色显示（低于 99% 或超出参考频率上限仍为橙色警示）；处理效率 ≥99.9% 时绿色显示。颜色与其他绿色指标一致（SeaGreen）。说明书中已同步补充该规则。

v2.6.1 修复指标卡长文本换行后的显示：触发/Busy、USB输出丢行、FWHM 等值在卡片固定高度内换行时，把鼠标移到该数值文字上滚动滚轮即可上下查看被裁剪的第二行及后续行。单行文本不拦截滚轮；字体仍由 TextRenderer 直接绘制（不经过位图、保留 ClearType），与普通 Label 逐像素一致；交互、公式悬停、点击详情、布局与配色均与之前完全一致。

v2.6.0 统一了空谱、缩放和道址模式切换的坐标状态：启动后即显示完整坐标轴；顶部可精确输入显示起止道，可一键放大主峰、ROI或恢复全谱，鼠标滚轮可围绕指针连续缩放。全谱65536道仍按显示宽度抽点，局部放大后自动恢复逐道绘制；统计和导出始终读取完整原谱。游标默认在鼠标附近吸附局部峰，显示该峰的局部FWHM和分辨率，也可切换为自由道址。4096/8192/16384/65536道切换会原子化复位显示范围、游标和谱缓存，避免沿用旧坐标。系统标准线性标定改为默认启用且可编辑，不再提供板号专用载入项。

v2.5.0 增加谱图内部的科学读数游标。鼠标进入实际绘图区后，竖直游标吸附到对应逻辑能道，内部读数卡实时显示该道精确计数、ADC 道中心电压、道宽、对应原始 16 位码范围，以及按当前增益/阻抗配置换算的板端和源端等效幅值。读数来自完整直方图，不使用绘图抽点值；4096/8192/16384/65536 道模式均保持一致的 2.5 V 映射。卡片自动在绘图区内左右、上下避让；左键锁定/解除，右键或 Esc 隐藏。游标层限速刷新且不参与采集、USB 接收、ROI、统计或导出计算。

v2.4.0 将公式提示改为上位机窗口内部的悬浮卡片。卡片会依据指标位置自动向左/向上避让，并在窗口客户区内钳位，因此最右下角指标也不会越过程序或电脑屏幕边缘。指标卡增加统一的青色识别条与细边框，鼠标停留 0.85 秒显示简式，单击打开完整公式页。USB CDC 发现列表按端口名去重；未连接时每 2 秒进行一次轻量扫描，只有端口集合变化才刷新下拉框，不抢焦点也不打断当前选择。

v2.3.1 调整交互节奏：自动发现端口后 COM 下拉框不再抢占启动焦点或出现蓝色选中态；公式悬停需稳定停留约 0.85 秒才显示，避免鼠标经过时频繁弹出。单击指标卡仍可立即打开完整公式与适用条件。

v2.3.0 改进交互体验：USB CDC 端口自动发现并保留当前选择，无须反复点击刷新；公式悬停延迟缩短；左侧命令改为“数值/选项 + 应用”同行布局；标记幅度支持 100–900 mV 内任意 1 mV 值；输入阻抗、发生器幅度和参考脉冲率均支持 0.1 单位微调。后台状态与图表刷新不会读取正在编辑的数值框，输入完成前不再自动提交、重排文字或移动光标。

v2.2.0 为产品化界面版本：移除每个物理量标题旁重复的 `ƒ(x)`，整块指标卡仍可悬停查看公式、单击打开公式详情；统一主色、按钮层级、页签、图表、指标卡和日志区视觉，并增大主图有效空间。采集算法、物理公式、USB 协议和固件均未改变。

v2.1.2 重新设计公式交互：悬停显示简洁的“计算公式”卡片；单击打开公式详情窗口，继续保留排版后的分式，并分区显示变量、物理意义、计算口径与适用条件。该改动仅涉及上位机显示，不改变计算公式、USB 协议或固件。

- 连接 STM32 原生 USB CDC 后，在“采集与显示”页选择 4096、8192、16384 或 65536 道并点击“应用道址”。
- 4096 道：MCU 本机累计，USB 只传整幅直方图，适合约 100 kcps 高速连续测量。
- 8192/16384/65536 道：固件批量发送 AD7980 原始 16 位码，PC 按所选道数累计；包带序号和 CRC16，可检测丢失。
- 状态区默认只显示摘要和有意义的操作/告警；“日志显示”可切换为完整协议。
- 标题栏“说明书”按钮包含安全接线、道址模式、指标定义和故障排查。
- 状态指标整卡可交互：稳定悬停可看窗口内公式卡片，点击标题、数值或所在区域可查看公式、单位、适用条件和误用提示。
- 通过率改为同一 MCU uptime 窗口内的 `样本增量/时间增量/参考频率`，清谱、切换模式或计数器复位后会等待下一条状态建立新基线，避免混用不同时间窗。
- “输入/阻抗/校准”页默认启用系统标准线性标定：`测得值 = 1.004148380 × 实际值 - 1.160606 mV`。斜率、截距和前端增益均可编辑，也可关闭标定以仅按增益换算。
- 能谱 CSV/TXT 始终导出所选逻辑道数的原始累计值，指标平滑不会改写原谱。

配套固件必须报告 `fw=2.0.0-adaptive`、`adc_spectrum_fs_mV=2500`，且 `hist_channels` 与界面一致。版本不匹配时软件会警告，不应使用其绝对幅度结果。
