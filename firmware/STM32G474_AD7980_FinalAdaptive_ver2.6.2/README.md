# STM32G474 + AD7980 最终自适应 MCA v2.5.0

本工程把原 4096 道高速版和满 16 位版合并为一个固件与一个上位机。AD7980-ARM 与 AD7980-BRM 的数字接口和软件时序相同，均使用外部模拟硬件产生 CNV、SDO Busy 指示、17 个 SCK 边沿释放串行口，并在读取后产生 PH_RESTART。

## 推荐模式

| 模式 | 数据路径 | 理想显示道宽（2.5 V满量程） | 建议用途 |
|---|---|---:|---|
| 4096 道 | MCU本机累计，整谱低频上传 | 610.35 µV | 100 kcps、长时间稳定采集、比赛默认 |
| 8192 道 | 原始16位码批传，PC重分道 | 305.18 µV | 兼顾峰形与吞吐 |
| 16384 道 | 原始16位码批传，PC重分道 | 152.59 µV | 精细标定，需观察USB丢失计数 |
| 65536 道 | 满16位原始码批传 | 38.147 µV | 低/中计数率诊断；不等同于16位有效分辨率 |

高道数只减小直方图量化步长，不会改善 AD7980 的实际 ENOB，也不会消除前端噪声、发生器幅度离散、触发时间游走或峰保持建立误差。4096 道对窄峰存在分箱量化，可能把非单调峰宽掩盖掉。

## 安全引脚

- PA0：ADC_BUSY_IRQ（输入）
- PA1：PH_RESTART（唯一峰保持复位输出）
- PA4：THRESHOLD_DAC
- PA5：ADC_SCK
- PA6：ADC_SDO（输入）
- PA11/PA12：USB DM/DP
- PA2、PA3、PC4、PC5、PF2：数字板硬接地，固件与 `.ioc` 均锁定为 Analog/High-Z，禁止改为输出或串口。
- CNV 完全由模拟触发链产生，MCU 不分配 CNV GPIO。
- LCD/FPC 必须拔除/禁用，USART 未启用。

## 编译与烧录

1. 在 STM32CubeIDE 导入 `STM32CubeIDE` 文件夹，工程名应显示为 `STM32G474_AD7980_FinalAdaptive`。
2. 选择 `Release`，执行 Clean Project 后 Build Project。
3. 运行 `STM32G474_AD7980_FinalAdaptive.launch`，确认控制台出现 `Download verified successfully`。
4. 也可烧录 `Firmware/STM32G474_AD7980_FinalAdaptive.hex`。
5. 双击 `PC_Monitor/启动上位机.bat`，连接 USB CDC，并选择所需道址。

上位机 v2.5.0 会在未连接时自动发现 USB CDC 串口并保留当前选择；不会自动连接或发送命令。配置项采用同行“输入 + 应用”布局，数值编辑期间后台刷新不会提交文本或移动光标。标记幅度支持 100–900 mV 内任意 1 mV 设置；这是测试标记与报告元数据，不控制外部信号发生器。

v2.3.1 进一步收敛界面干扰：启动时 COM 下拉框不抢焦点；指标公式仅在稳定悬停约 0.85 秒后显示，单击仍可立即查看完整说明。

v2.4.0 把公式提示改为程序窗口内悬浮卡片：对最右侧和最下方指标自动向左、向上避让，并始终限制在上位机客户区内。USB CDC 名称按大小写无关方式去重；未连接时每 2 秒轻量扫描一次，仅在端口集合变化时重绘列表，避免重复 COM8、抢焦点或无意义占用。指标卡的识别色、边框和交互层级也已统一。以上改动只涉及上位机界面与端口发现，固件、采集时序和物理计算未改变。

v2.5.0 增加谱图内部科学读数游标：实时显示吸附能道、完整直方图精确计数、ADC中心电压、道宽、原始16位码范围及当前配置下的板端/源端等效幅值。左键锁定，右键或Esc隐藏，卡片会在绘图区内自动避让。游标显示不改变原始谱、ROI、FWHM、统计或导出结果。

默认比较器端阈值为 100 mV。固件按 1 kΩ/(9.1 kΩ+1 kΩ) 自动补偿，DAC 引脚约输出 1.010 V。允许设置范围 50–200 mV。

## 科学指标说明

- 峰位、均值和导出谱均由原始计数计算。
- FWHM 指标在高道数模式仅使用很小的对称平滑窗口提高半高交点鲁棒性；不会回写或平滑导出谱。
- 分辨率定义为 `FWHM / 峰位 × 100%`。比较不同幅度时还应同时比较 FWHM 的 mV 值、峰是否单峰对称、ROI与样本数。
- 脉冲通过率定义为 `同一测量窗内样本增量 / (参考频率 × MCU uptime 增量) × 100%`。清谱、切换道址或固件计数器回零后，上位机会等待新状态帧重建基线，禁止把清零后的分子与清零前的计时混用。
- 统计精度显示为净峰面积 `N` 的理想泊松相对标准不确定度 `100%/sqrt(N)`；它不包含发生器漂移、基线漂移、标定误差和系统误差。
- 所有计算型状态项均支持悬停提示和点击公式说明，界面说明只读，不会向 MCU 发送 GPIO/CNV 控制。
- 03 板 100 kHz 数据可选用一次线性修正，默认仍关闭；斜率、截距和前端增益均可编辑，保留原有按固定增益直接换算的行为。
- 若 110 mV 附近相对分辨率突然恶化而相邻幅度恢复，优先检查 FPGA 10位 DAC 的码型/量化、波形形状方差、触发时间游走及谱峰肩部；简单线性映射代码不会只在某个幅值制造非单调峰宽。

## 验证结果

- STM32CubeIDE Release：0 errors、0 warnings。
- Windows 上位机编译及内置协议/谱学自检通过。
- 静态安全检查覆盖接地针高阻、无USART、USB引脚、外部CNV、16位读取与第17边沿、读后Restart、USB超时恢复及阈值范围。

最终仍需在实板上分别做 4096/8192/16384/65536 道的持续计数测试，记录 Overrun、USB恢复和序号缺口；高计数率下以4096道结果为准。
