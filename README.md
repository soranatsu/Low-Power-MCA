# Low-Power-Energy-Spectrometer
TH234U

This Github page is intended for group-based development of the low power energy spectrometer. The project file shown includes both firmware and software development. 
Up to 2026.7.29, the schematic design of Anaglog PCB has been verified and PCB layout is to be confirmed within 2 days. 
Meanwhile, design of the power module and STM32 board conjunction part is ongoing. Coding with vide assistance is going to be applied for rapid development of STM32 controlling logics.
